# setup-agent-core-project 공통 진입

- 목적: 승인된 프로젝트 스킬 등록 개정을 두 도구의 같은 실행 본문에 연결한다.
- 읽는 시점: 이 스킬의 native 진입이 선택됐을 때.
- 책임: Core는 보관·연결을, 스킬은 고유 절차와 산출물 조건을 소유한다.
- 상태: current가 실행 정본이고 source는 비활성 보존 원본이다. 실제 설치·사용 상태는 Consumer가 소유한다.
- 관련 권위: [공개 스킬 계약](../../docs/COMPATIBILITY.md#3b-공통-workflow-진입-계약).

[실행 스킬](current/SKILL.md)을 끝까지 읽고 고유 순서·질문·정지·검증·커밋·보고 조건을 적용한다. 상대 참조는 current 디렉터리를 기준으로 읽는다. source는 원본 bytes와 메타데이터를 보존하는 비활성 자료이며 동시에 적용하지 않는다.

현재 도구의 명시적 `setup-agent-core-project` 스킬 호출은 실행 정본의 직접 호출로 해석한다. Codex와 Claude Code의 native 호출 표기 차이만 진입에서 연결한다. 승인 개정은 초기 native 등록과 갱신 시 대조를 추가하며 기존 프로젝트 구성·인증·게시 절차를 보존한다.

스킬 절차를 Core의 일반 작업 기본값으로 대체하거나, 절차가 다르다는 이유만으로 스킬 수정·실행 중단을 요구하지 않는다. 실제 문제를 발견하면 근거·영향·확인 한계를 보고할 수 있으나 보고가 원본 수정 승인은 아니다. 실행 정본에 도달할 수 없으면 그 사실을 보고하고 보존 원본이나 과거 기억으로 대신하지 않는다.

# Core 검토용 채팅 인계 문서 항목

- 목적: 원래 대화 없이 검토할 수 있는 최소 근거와 개선 후보를 구성한다.
- 읽는 시점: 채팅 분석에서 후보가 발견돼 보고서를 작성할 때.
- 책임: 분석 에이전트가 근거를 작성하고 Maintainer가 현재성을 재검토한다.
- 상태: 보고 구성 참고 자료. 활성 규칙이나 구현 설계가 아니다.
- 관련 권위: [채팅 분석 본문](../SKILL.md).

## 문서 공통 정보

- 목적·작성 시점·분석 범위·책임·상태(`검토 후보 / 미승인`)·관련 입력.
- 원래 목표, 작업 환경과 Core 적용 여부. 모르는 환경은 미확인으로 표시.
- 관측한 대화 구간과 실행 근거, 접근하지 못한 기록 및 요약의 한계.
- Core 대조 여부, 확인한 문서·제공된 기준과 그 한계. 기준이 없으면 `core_not_checked`.

## 후보별 정보

- ID와 요약, 필요한 개선 / 선택적 개선 / 근거 부족.
- 상황·기대 결과·실제 결과·사용자 교정·해결 및 검증 여부. 핵심 근거는 최소 발췌와 맥락으로 포함.
- 사실 / 추론 / 미검증의 구분, 원인 분류 또는 미분류 이유.
- 기존에 해결된 부분, Core에 적합한 이유, 특정 도메인에 남길 부분.
- 현재 소유자·예상 경로(미확정 허용), 적용 조건과 적용하면 안 되는 정상 사례.
- 일반화 근거와 부족한 근거, 최소 변경 제안, 미개선 영향.
- 검증 가능한 성공 조건·방법 및 `not_run` 항목.
- 승인·보류·거절 상태. 사용자가 승인하지 않은 것은 미승인 후보.

## 재개 요청

“이 후보의 근거를 확인하고 최신 Core와 비교해 중복, 소유권, 일반화 적합성, 최소 변경안과 검증을 보고한다. Core 변경은 정확한 대상·이유·현재 사용자 승인 후 수행한다.”

후보별 미확인 질문을 덧붙인다. 비밀이나 불필요한 원문 전체 대신 필요한 관측 근거만 남긴다.

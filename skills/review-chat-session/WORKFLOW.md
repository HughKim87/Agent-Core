# 채팅 세션 분석 진입

- 목적: Core 없는 프로젝트·채팅을 분석하는 개인용 스킬의 실행 본문을 연결한다.
- 읽는 시점: 이 스킬이 선택됐을 때.
- 책임: Core는 원본·배포를, 설치한 사용자는 설치본과 결과를 소유한다.
- 상태: 공통 설치용. 프로젝트 native 등록 대상이 아니다.
- 관련 권위: [공개 스킬 계약](../../docs/COMPATIBILITY.md#3b-공통-workflow-진입-계약).

[실행 본문](current/SKILL.md)을 읽는다. 공통 설치는 본문과 필요한 자료를 독립 패키지로 제공하며 프로젝트 Core 경로를 참조하는 포인터만 설치하지 않는다.

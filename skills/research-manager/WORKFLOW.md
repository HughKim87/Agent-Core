# research-manager 공통 진입

- 목적: 심층 연구 스킬의 보존 원본과 같은 절차를 두 도구에 연결한다.
- 읽는 시점: 사용자가 깊게 리서치해 또는 깊게 조사해 요청하여 이 스킬이 선택됐을 때.
- 책임: Core는 보관·배포를, 스킬은 연구 절차와 산출물 조건을 소유한다.
- 상태: source 실행 정본. PC 공통 설치용이며 프로젝트 native 등록 대상이 아니다.
- 관련 권위: [공개 스킬 계약](../../docs/COMPATIBILITY.md#3b-공통-workflow-진입-계약).

[실행 본문](source/SKILL.md)을 끝까지 읽고 고유 절차를 적용한다. Core 연결은 필요하지 않으며 스킬 수정·검토 요청은 연구 실행 호출이 아니다. 원본의 모델 지정·Agent 활용·실패 중단은 스킬 고유 설정으로 보존하고 Core 전역 기본값으로 사용하지 않는다. 공통 설치본에는 같은 본문을 포함하며 연구 결과·실행 기록은 작업 소유 프로젝트 또는 사용자 지정 위치에 둔다.

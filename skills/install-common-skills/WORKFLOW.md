# 공통 스킬 설치 진입

- 목적: Core 연결 프로젝트에서 승인된 개인용 스킬 설치·갱신 절차를 연결한다.
- 읽는 시점: 이 프로젝트 스킬이 선택됐을 때.
- 책임: Core는 배포 목록과 절차를, 사용자는 개인 설치 위치와 설치본을 소유한다.
- 상태: 프로젝트 설치용. 이 설치기 자체를 PC 공통 스킬로 설치하지 않는다.
- 관련 권위: [공개 스킬 계약](../../docs/COMPATIBILITY.md#3b-공통-workflow-진입-계약).

[실행 본문](current/SKILL.md)을 읽는다. 설치기 등록이나 스킬 제작 요청을 실제 개인용 설치 요청으로 해석하지 않는다.

# handoff-manager 원본 진입

- 목적: 원본 스킬과 참고 자료를 바꾸지 않고 같은 내용을 두 도구에 연결한다.
- 읽는 시점: 이 스킬의 native 진입이 선택됐을 때.
- 책임: Core는 보관·연결을, 스킬은 고유 절차와 산출물 조건을 소유한다.
- 상태: 원본 보존형 진입. 사용자 승인으로 직접 호출 전용이며 실제 설치·사용 상태는 Consumer가 소유한다.
- 관련 권위: [공개 스킬 계약](../../docs/COMPATIBILITY.md#3b-공통-workflow-진입-계약).

[원본 스킬](source/SKILL.md)을 끝까지 읽고 원본의 고유 순서·질문·정지·검증·커밋·보고 조건을 적용한다. 원본의 상대 참조는 원본 파일이 있는 source 디렉터리를 기준으로 읽는다. 참고 자료·메타데이터를 포함한 원본 트리와 내용은 그대로 보존한다.

현재 도구의 명시적 `handoff-manager` 스킬 호출은 원본이 정한 해당 스킬의 직접 호출로 해석한다. Codex와 Claude Code의 native 호출 표기 차이만 진입에서 연결하며 원본의 업무 절차를 바꾸지 않는다.

스킬 절차를 Core의 일반 작업 기본값으로 대체하거나, 절차가 다르다는 이유만으로 스킬 수정·실행 중단을 요구하지 않는다. 실제 문제를 발견하면 근거·영향·확인 한계를 보고할 수 있으나 보고가 원본 수정 승인은 아니다. 원본 내용이 필요할 때 이 진입문이나 과거 기억으로 대신하지 않는다.

## 호출 경계

사용자가 스킬 선택 UI에서 이 스킬을 선택하거나 해당 도구의 명시적 스킬 명령으로 호출했을 때만 실행한다. 인수인계·다음 세션 준비·핸드오프 작성 같은 단어나 일반 요청만으로 자동 선택하지 않는다. 스킬 자체의 수정·점검 요청도 실행 호출이 아니다. Codex의 `allow_implicit_invocation: false`와 Claude의 `disable-model-invocation: true`를 유지한다. 보존 원본 frontmatter의 자동 선택 설명은 원본 기록이며 활성 호출 조건이 아니다. 이 변경은 호출 경계에만 적용하고 원본의 문서 작성·점검·안전 절차는 그대로 적용한다.

# session-close 공통 진입

- 목적: 보존 원본을 유지하면서 사용자 승인 개정 본문을 두 도구에 연결한다.
- 읽는 시점: 이 스킬의 native 진입이 선택됐을 때.
- 책임: Core는 보관·연결을, 스킬은 고유 절차와 산출물 조건을 소유한다.
- 상태: current가 실행 정본이고 source는 비활성 보존 원본이다. 실제 설치·사용 상태는 Consumer가 소유한다.
- 관련 권위: [공개 스킬 계약](../../docs/COMPATIBILITY.md#3b-공통-workflow-진입-계약).

[실행 정본](current/SKILL.md)을 끝까지 읽고 그 고유 순서·질문·승인·검증·커밋·보고 조건을 적용한다. 상대 참고 자료는 current 안의 해당 파일을 기준으로 읽는다. source 트리와 SOURCES.json은 원본 식별을 위해 그대로 보존하지만 실행 정본과 함께 적용하거나 이전 절차로 되돌리는 근거가 아니다.

현재 도구의 명시적 `session-close` 스킬 호출은 실행 정본이 정한 해당 스킬의 직접 호출로 해석한다. Codex와 Claude Code의 native 호출 표기 차이만 진입에서 연결한다. 개정 본문은 사용자가 승인한 로컬 변경 작업 방식 선택과 이번 호출 생성 자원의 정리를 반영하며 Core 일반 기본값에 맞춘 재작성은 아니다.

스킬 절차를 Core의 일반 작업 기본값으로 대체하거나, 절차가 다르다는 이유만으로 스킬 수정·실행 중단을 요구하지 않는다. 실제 문제를 발견하면 근거·영향·확인 한계를 보고할 수 있으나 보고가 내용 수정 승인은 아니다. 실행 정본에 도달할 수 없으면 그 사실을 보고하고 이 진입문·보존 원본·과거 기억으로 대신하지 않는다.

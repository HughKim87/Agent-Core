# 원자 쓰기와 상태 무결성

- 목적: 현재 규칙에서 도출할 수 없는 원자 상태 쓰기의 최소 진단 불변식을 보존한다.
- 읽는 시점: 원장 append, 동시 쓰기, 상태 스냅샷 기능을 실제로 도입할 때만.
- 책임: 에이전트가 해당 기능 도입 시 계약·테스트에 흡수하고 사용자가 이후 삭제를 승인한다.
- 상태: 최소 유지. 기본 컨텍스트와 일반 route에서 제외.
- 관련 권위: [실패 경험의 예방책 흡수](../rules/failure-records.md).
- 비자명 잔여: 잠금 밖의 사후 재읽기는 쓰기 성공 판정의 경쟁 구간을 닫지 못한다.

---

## 비자명한 잔여 진단

쓰기 성공 판정에 쓰는 해시·개수·버전은 쓰기와 같은 잠금 내부 스냅샷에서 계산해야 하며, 잠금 밖의 사후 재읽기는 검증을 추가해도 경쟁 구간을 닫지 못한다.

현재 Core에는 원장·동시 상태 쓰기 Runtime이 없다. 해당 기능이 실제 범위에 들어올 때 이 불변식을 구현 계약과 정상·실패 회귀 테스트로 옮긴 뒤 이 문서를 종료한다.

# 범위·권한·목적 경계

- 목적: 승인된 범위를 넘어 작업이 확대되는 실패를 막는다.
- 읽는 시점: 큰 작업의 범위를 정할 때, 과거 자료를 검토할 때, 사용자가 해석을 교정할 때.
- 책임: 에이전트가 재발 시 조건과 검증을 보강한다.
- 상태: 해결.
- 관련 권위: 라우터가 선택하는 실패 기록 규칙.

---

## 증상

승인된 현재 범위를 넘어 미래 기능, 역사 전체, 추가 산출물을 작업에 포함했다. 기반 기능이나 과거 예시를 최상위 목표로 확대했다.

## 조건

최신 사용자 지시, 활성 정본, 과거 증거의 권위 차이를 구분하지 않은 상태.

## 확인된 원인

승인을 절차 통과 표시로 취급하고 권위의 출처를 구분하지 않았다. 에이전트의 제안을 사용자 지시로 취급했다.

## 실패한 접근

지적받은 항목만 그때그때 수정했다. 근본 원인이 권위 판정에 있었기 때문에 같은 확대가 다른 형태로 반복됐다.

## 해결

최신 사용자 지시와 정확한 대상·변화·제외·위험을 먼저 고정하고 그 안에서만 실행한다. 작업 등급을 먼저 정한다.

## 검증

범위 확장 시나리오를 승인 판정표에 대입해 차단되는지 확인한다.

## 예방

- 권위는 최신 사용자 지시 → 상시 정책 → 활성 소유자 순으로 판정한다.
- 대화·보고서·위임 결과는 발화자와 권위를 분리한다. 에이전트 제안은 승인 없이 정책이 되지 않는다.
- 사용자가 해석을 교정하면 대기 중 변경을 무효화하고 재계산한 뒤에만 재개한다.
- 미래 기능이 현재 결과에 필수임이 증명되지 않으면 구현하지 않는다.
- 분석 권한은 구현이나 추가 산출물 생성 권한이 아니다.

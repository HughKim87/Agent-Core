# 런타임과 텍스트 경계

- 목적: 예방책 흡수가 끝난 과거 사례의 종료 대상을 식별한다.
- 읽는 시점: 이 파일의 삭제 승인을 판단할 때만.
- 책임: 에이전트가 예방 소유자를 유지하고 사용자가 삭제를 승인한다.
- 상태: 흡수 완료, 종료 대기. 활성 예방 정본이 아니다.
- 관련 권위: [호환성 계약](../docs/COMPATIBILITY.md), 텍스트 경계 결함 주입 테스트.
- 예방 소유자: `tests/test_integrity.py`.

---

## 흡수 판정

UTF-8·줄바꿈·실행 Runtime 경계와 회귀 검사는 관련 권위와 테스트가 소유한다. 이 문서에만 남는 비자명한 진단 정보는 없다.

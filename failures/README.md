# 실패 지식 색인

- 목적: 원인별 해결 실패 정본으로 가는 링크만 소유한다.
- 읽는 시점: 과거에 실패했던 영역에 새 작업이 진입할 때.
- 책임: 에이전트가 사례 추가 시 갱신한다.
- 상태: 활성 색인.
- 관련 권위: 라우터가 선택하는 실패 기록 규칙.

현재 미해결 차단은 이 폴더가 아니라 현재 상태 문서가 소유한다.

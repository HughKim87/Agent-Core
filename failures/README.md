# 예외 진단 문서

- 목적: 현재 규칙·테스트에서 도출할 수 없는 최소 진단 문서와 종료 대기 범위를 구분한다.
- 읽는 시점: 명시적으로 비자명한 과거 진단이 필요하거나 종료 대상 삭제를 판단할 때만.
- 책임: 에이전트가 최소 유지 조건을 감사하고 사용자가 삭제·이동을 승인한다.
- 상태: 선택 정보. 활성 라우터가 아니며 기본 컨텍스트에서 제외.
- 관련 권위: [실패 경험의 예방책 흡수](../rules/failure-records.md).

현재 미해결 차단은 이 폴더가 아니라 현재 상태 문서가 소유한다. 해결된 실패의 예방책은 관련 규칙·테스트가 소유한다.

## 최소 유지

- [원자 쓰기와 상태 무결성](atomic-state-integrity.md)

그 밖의 사례는 예방책 흡수가 끝난 종료 대기 표식이다. 일반 작업에서 검색하거나 읽지 않는다. 정확한 삭제 대상은 최종 개선 보고서에서 사용자 승인을 받는다.

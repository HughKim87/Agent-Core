# 보호 경로의 간접 노출

- 목적: 본문을 읽지 않아도 보호 데이터가 노출되는 경로를 막는다.
- 읽는 시점: 보호 경로가 있는 트리를 검색·색인·링크할 때.
- 책임: 에이전트가 재발 시 조건과 검증을 보강한다.
- 상태: 해결.
- 관련 권위: 라우터가 선택하는 실패 기록 규칙.

---

## 증상

보호 폴더 본문을 읽지 않았는데 활성 링크와 문서 그래프가 경로와 이름을 노출했다.

## 조건

도구 제외 설정, 재귀 탐색 사전 필터, 활성 문서 링크가 각각 독립된 경계인 상태.

## 확인된 원인

세 경계를 하나로 보고 하나만 적용하면 충분하다고 판단했다. 이후 교차검증의 신뢰도를 높인다는 이유로 정확한 대상 승인 없이 보호 경로를 읽는 재발도 있었다.

## 실패한 접근

도구의 제외 설정만 적용했다. 활성 링크가 여전히 노출했다.

## 해결

도구 제외 설정, 파일시스템 사전 필터, 활성 링크 검사를 각각 적용한다.

## 검증

보호 경로가 재귀 탐색 전에 배제되고 활성 링크에 나타나지 않는지 검사한다.

## 예방

- 열거는 읽기와 같은 취급이다. 정확한 대상과 목적 승인 전에 열거하지 않는다.
- 보고서나 교차검증 자료에 보호 경로가 언급되어도 새 접근 권한이 생기지 않는다.
- 보호 경로를 클릭 가능한 링크나 전체 목록에 넣지 않는다.
- 도구의 제외 설정과 문서 연결 그래프를 별도로 검사한다.

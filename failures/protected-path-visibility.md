# 보호 경로의 간접 노출

- 목적: 예방책 흡수가 끝난 과거 사례의 종료 대상을 식별한다.
- 읽는 시점: 이 파일의 삭제 승인을 판단할 때만.
- 책임: 에이전트가 예방 소유자를 유지하고 사용자가 삭제를 승인한다.
- 상태: 흡수 완료, 종료 대기. 활성 예방 정본이 아니다.
- 관련 권위: [보호 데이터와 외부 효과](../rules/protected-data.md).
- 예방 소유자: `rules/protected-data.md`.

## 흡수 판정

열거·검색·링크·외부 효과의 사전 차단은 관련 권위가 소유한다. 이 문서에만 남는 비자명한 진단 정보는 없다.

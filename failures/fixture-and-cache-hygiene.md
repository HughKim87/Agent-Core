# 검증 fixture와 작업공간 위생

- 목적: 검증 행위 자체가 대상을 오염시키는 것을 막는다.
- 읽는 시점: 읽기 전용 대상에서 검사를 실행할 때, 테스트 fixture를 만들 때.
- 책임: 에이전트가 재발 시 조건과 검증을 보강한다.
- 상태: 해결.
- 관련 권위: 라우터가 선택하는 실패 기록 규칙.

---

## 증상

읽기 전용으로 선언한 트리에서 테스트를 실행해 캐시 파일이 생성됐다. 그 직후 변경 0건이라고 보고했다.

## 조건

검사 명령이 부작용을 남기는 기본 설정으로 실행된 상태.

## 확인된 원인

읽기 전용 선언을 파일을 편집하지 않는 것으로만 해석하고 실행 부작용을 포함하지 않았다.

## 실패한 접근

변경 여부를 편집 도구 기준으로만 확인했다. 도구가 만든 파일은 확인 대상에서 빠졌다.

## 해결

읽기 전용 대상에서 부작용을 남기는 실행을 하지 않는다. 필요하면 사본에서 실행한다.

## 검증

실행 후 대상 트리에 새 파일이 생기지 않았는지 확인한다.

## 예방

- 읽기조차 부작용을 남기는 실행은 사본에서 한다.
- 부작용 억제 옵션은 승인 게이트 명령의 일부로 취급한다.
- 변경 0건 보고 전에 도구가 생성한 파일을 포함해 확인한다.
